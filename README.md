# Touristico
## Databases class project

The goal of this class was to develop a database for a fictional tourism app. The frontent was provided by a different class group (mobile development) and my task was to implement a database that stores tourist user data and touristic destinations they can visit. The app was intended to mobile phones so the project was created in Kotlin. 

The app differentiated between admin login and user login. 
Admin login allowed adding, editing and deleting both touristic destination and user records, while user login only allowed adding, editing and deleting own user record.
